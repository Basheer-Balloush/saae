- Feedback survey: questions live only in src/lib/feedback-survey.ts; public writes go through server functions (honeypot + IP rate limit), reads/updates only by `admin` role via RLS — keeps contact data out of public queries.
- Course feedback (LMS, after lessons + quiz, before the certificate) is separate from that survey: forms live in the database (`lms_feedback_forms` + frozen `lms_feedback_form_versions`, edited by LMS admins; `DEFAULT_FORM` in src/lib/course-feedback-survey.ts only seeds the default). All writes go through server functions; learners read their own response, LMS admins read everything, instructors nothing.
